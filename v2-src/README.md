# Нейролаб 11 — версия 2 (исходный код)

Интерактивный тренажёр к уроку информатики «Средства искусственного интеллекта», 11 класс.
Версия 2 написана на React 19 и TypeScript.

- `src/lib/perceptron.ts` — модель нейрона: взвешенная сумма, пороговая функция, правило обучения, разделяющая прямая.
- `src/data/content.ts` — содержание пяти заданий.
- `src/hooks/` — состояние тренажёра (useReducer + localStorage), маршруты по заданиям, тема.
- `src/components/` — интерфейс заданий.

Сборка: `npm install`, затем `npm run build` — готовые файлы попадают в папку `../v2`.
