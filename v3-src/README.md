# Нейролаб 11 — версия 3 (исходный код)

Интерактивный тренажёр к уроку информатики «Средства искусственного интеллекта», 11 класс.
Версия 3 написана на React 19 и TypeScript. Оформление — «витрина»: тёмный фон, только нейтральные цвета,
задания показаны как предметы вокруг модели нейрона.

- `src/lib/perceptron.ts` — модель нейрона: взвешенная сумма, пороговая функция, правило обучения, разделяющая прямая.
- `src/data/content.ts` — содержание пяти заданий.
- `src/hooks/useLab.ts` — состояние тренажёра (useReducer + localStorage).
- `src/hooks/motion.ts` — параллакс первого экрана, анимация счёта, листание заданий стрелками, плавная смена заданий.
- `src/components/` — интерфейс: первый экран, навигация, пять заданий.

Сборка: `npm install`, затем `npm run build` — готовые файлы попадают в папку `../v3`.
